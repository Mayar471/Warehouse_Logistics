# اختيار منشأ طلب تريند سي

نُفذ محليًا بتاريخ 11 أكتوبر 2026. الاختيار من متجر أو مستودع مملوك لبيت الشام داخل دمشق يملك كامل السلة في الموقع نفسه بأرصدة متسقة مع الحركات والالتزامات. لا يستخدم مخزون تاجر آخر أو المحجوز والمعزول أو موقع خارج التغطية.

تُصفى المواقع بواسطة مفاتيح المخزون في قاعدة البيانات ثم تُفحص المطابقة. الأولوية للموقع الحالي عندما يكون مؤهلًا ثم ترتيب ثابت بمعرف الموقع. رسوم التجربة متساوية ولا توجد بيانات مسارات موثوقة؛ السياسة الحالية ليست تحسينًا جغرافيًا أو ادعاءً بكلفة مثلى. تقسيم السلة ومستودعات مشتركة ومدن إضافية لاحقًا.

التوفر لكل منتج هو أكبر كمية قابلة للبيع في موقع مؤهل واحد، وليس مجموع المواقع. لا يضمن ذلك تنفيذ كل مزيج منتجات؛ عند حساب التوصيل يُفحص كامل المزيج وتظهر رسالة واضحة إذا تعذر تنفيذه من منشأ واحد.

الاختيار وحفظ عرض الخدمة والسلة بمعاملة واحدة. ملخص الطلب يعرض اسم الموقع؛ العرض يثبت معرفه دون حجز. عند التأكيد تُراجع الخدمة والاتساق وتُحجز كامل السلة ذريًا من الموقع المثبت. نفاد الكمية يعيد حساب العرض دون تبديل المنشأ بصمت. فقد الرد يسمح بإعادة نفس التأكيد دون تكرار الطلب.

الأدلة: tests/storefront-origins.test.ts، tests/inventory.test.ts، scripts/storefront-origin-check.ts. الاختبارات معزولة ولا تضيف كميات لقاعدة العرض الدائمة.
