# مشاركة خريطة المندوب

الحالة: نُفذت شريحة محلية لمشاركة GPS أثناء توصيل الشحنات بتاريخ 11 أكتوبر 2026. خريطة لوحة الملخص السابقة ما زالت توضيحية؛ خريطة «موقع المندوب» الجديدة تستخدم آخر قراءة مرسلة من جهاز المندوب. تشغيل إنتاجي وتتبّع خلفي مستمر لم يُنفذا بعد.

الهدف: يشارك المندوب موقعه أثناء التوصيل، ويشاهده العميل والمتجر والعمليات بحسب صلاحياتهم في الشحنة نفسها. مشاهدة شحنة لا تمنح حق مشاهدة جميع مهام المندوب.

الاتجاه المقترح للخريطة: استخدام بيانات OpenStreetMap، مع مزود عرض قابل للتبديل بحسب التكلفة والاعتمادية؛ خدمات المسارات والبحث عن العناوين مستقلة، ومشاركة GPS تنفذ داخل نظامنا. لا يُعتمد خادم البلاطات العام بوصفه خدمة إنتاج مضمونة: [سياسة OSM الرسمية](https://operations.osmfoundation.org/policies/tiles/) تفرض إظهار نسبة البيانات للمساهمين واحترام التخزين المؤقت وتمنع التنزيل الجماعي والعمل دون اتصال عبر هذا الخادم. الاستضافة الذاتية أو مزود يعتمد بيانات OSM خياران يُقاسان عند التوسع؛ لم يُثبت المزود النهائي بعد.

## ما يعمل الآن

- يظهر «موقع المندوب» بتفاصيل الشحنة للعمليات والمتجر والمندوب، وبـ«طلباتي» في متجر تريند سي لصاحب الطلب. لا يُعرض الموقع في رابط التتبع العام ولا لحساب نقطة الاستلام أو متجر أو مندوب آخر.
- يبدأ المندوب المكلف المشاركة بعد استلام العهدة وبدء التوصيل، بموافقة صريحة وإصدار الشحنة. يمكنه السماح للعميل أو قصر المشاهدة على المتجر والعمليات. مهلة المنح 30 دقيقة؛ الإيقاف للمندوب أو العمليات، والتجديد يتطلب تفعيلًا جديدًا. لا يُنشأ رابط عام للإحداثيات.
- دورة المشاركة مستقلة بمعرف عشوائي يتغير عند التفعيل الجديد. تصل القراءة بتسلسل ووقت قياس ودقة؛ تُرفض الإحداثيات غير الصالحة ووقت القياس الأقدم من دقيقتين أو المستقبل بأكثر من 10 ثوانٍ أو غير المتزايد. نفس التسلسل ونفس المحتوى يعيدان الإقرار دون تجديد عمر القراءة، ونفس التسلسل بمحتوى مختلف يُرفض.
- API يحدد الإرسال مرة كل خمس ثوانٍ على الأقل لكل شحنة، والواجهة ترسل بحد عشر ثوانٍ وتعيد نفس القراءة المعلقة عند فقد الرد. مشاهدة الموقع تُطلب كل عشر ثوانٍ عند فتح اللوحة وظهور الصفحة، مع طلب قراءة واحد معلّق لكل لوحة. تُوقف مراقبة GPS عند إخفاء الصفحة أو إغلاق العرض؛ استئنافها يتم من الزر. ليست خدمة خلفية للهاتف.
- تُحفظ آخر قراءة فقط، بلا سجل مسار. لا تضاف إحداثيات إلى timeline أو outbox أو سجل الموافقة. الإيقاف وانتقال حالة الشحنة أو تغيير التكليف يمسحان الإحداثيات بمعاملة الحالة نفسها. انتهاء المهلة يُحجب عند القراءة مباشرة دون انتظار العامل، ثم يمسح عامل المتابعة البيانات؛ الحد الاحتياطي للاحتفاظ 24 ساعة.
- القراءة الأقدم من دقيقتين تُحجب، وكذلك عند فشل التحديث أو فقد صلاحية المشاهدة. الواجهة تطبق وقت انتهاء القراءة محليًا اعتمادًا على وقت الخادم وزمن منقضٍ رتيب مع احتساب زمن الطلب بصورة تحفظية. يظهر وقت القياس ودقة GPS ودائرة الخطأ، ولا تُحرّك العلامة بمحاكاة ولا يعرض ETA أو مسارًا غير محسوب. إيقاف المنح ينعكس فورًا في API، وبحد دورة قراءة عشر ثوانٍ عند المشاهد المتصل.
- Leaflet 1.9.4 مستوردة محليًا وتُحمّل الخريطة عند الحاجة. البلاطات الافتراضية لخدمة OSM العامة للعرض المحدود، مع نسبة واضحة للمساهمين وreferrerPolicy=origin لطلبات الصور دون عنوان الصفحة أو رمز تتبع. لا تنزيل جماعي أو تمهيد خارج المشاهدة. VITE_MAP_TILE_URL وVITE_MAP_ATTRIBUTION قابلان للضبط وقت البناء؛ إنتاج واسع يحتاج مزودًا بشروط واعتمادية ملائمتين. [Leaflet المستقرة](https://leafletjs.com/download.html)، [سياسة البلاطات](https://operations.osmfoundation.org/policies/tiles/).

## العقد

GET /api/shipments/:id/location للأدوار الداخلية المخولة؛ GET /api/storefront/orders/:id/location لصاحب جلسة الطلب. النتيجة state وserverTime وcanShare وpoint أو null. session متاحة للمندوب المكلف والعمليات فقط، وتضم المعرف والانتهاء والتسلسل التالي.

POST /api/shipments/:id/location/sharing مع idempotency-key:

```json
{"action":"start","expectedVersion":8,"consent":true,"customerAllowed":true}
```

```json
{"action":"stop","sessionId":"معرف UUID للجلسة","reason":"إيقاف المشاركة"}
```

POST /api/shipments/:id/location/points للمندوب المكلف فقط:

```json
{"sessionId":"معرف UUID للجلسة","sequence":1,"latitude":33.5138,"longitude":36.2765,"accuracy":18,"measuredAt":"2026-10-11T12:00:00.000Z"}
```

قيود قاعدة البيانات في ترحيل 11؛ لا تضاف مواقع اصطناعية للعرض الدائم. العقود صارمة، والموافقة والإيقاف والتدقيق ومنع تكرار الأوامر بمعاملة؛ فشل تدقيق الإبطال يعيد انتقال حالة الشحنة أيضًا.

## الأدلة والحدود

tests/location.test.ts تغطي الموافقة والعزل وانتحال المندوب والتتبع العام، وتكرار النقطة وعمرها والوقت والتسلسل ومعدل الإرسال، والمهلة دون عامل، والتفعيل الجديد، وإيقاف المنح والذرية وإبطال المشاركة عند التسليم والاستمرار بعد إعادة التشغيل. scripts/location-check.ts يغطي إذن GPS بمحاكاة الاختبار وفقد رد التفعيل ثم إعادة نفس الأمر، ومشاهدة العميل والإيقاف ونسبة OSM وأحجام 1440 و390 و360. صور الاختبار تستخدم بلاطات محلية موسومة TEST MAP TILE؛ لا تُحمّل بلاطات الخدمة العامة آليًا في الاختبارات، ولا تثبت المحاكاة دقة GPS ميدانية.

المصادقة إنتاجيًا والتشفير عبر HTTPS وخدمة الهاتف في الخلفية ومشاركة النقل بين المستودعات والإرجاع وروابط منح فردية خارج جلسة المتجر والسياسات حسب المؤسسة والمزود الإنتاجي والمسارات والتكلفة التكيفية وقياس الطاقة الفعلي لاحقة. GPS يحتاج HTTPS خارج localhost وإذن الجهاز، وقد يُزوَّر من عميل معدل؛ لا يوجد إثبات موقع مادي. فشل إذن الجهاز يُعرض بوضوح ويترك زر إيقاف المشاركة متاحًا.

## متطلبات التطوير اللاحق

نجح التشغيل الكامل بـ86 اختبارًا، واختبارات الموقع الخمسة مجددًا بعد تعزيز تحقق انتحال المندوب والإبطال عند التسليم بإثبات العميل. نجح البناء وفحص التنسيق ورحلة المتصفح، بما فيها فقد رد التفعيل والإيقاف وإعادة الأمر نفسه. يلزم تحقق ميداني على هاتف فعلي قبل ادعاء جاهزية GPS والطاقة للتشغيل.

أُعيد تشغيل العرض المحلي بترحيل 11. قراءة الموقع لشحنة دائمة تعيد حالة المشاركة دون إحداثيات اصطناعية، والأرصدة الستة ما زالت مطابقة دون اختلافات. لم تُفعّل مشاركة أو GPS مصطنع في بيانات المستخدم الدائمة بسبب الاختبارات.

- موافقة واضحة من المندوب وبدء وإيقاف المشاركة مع حالة ظاهرة.
- إحداثيات ووقت قياس واستقبال ودقة GPS وتسلسل؛ رفض الموقع غير الصالح والقديم والتحديثات خارج الترتيب، والتحقق من تكليف المندوب.
- منح وصول مرتبط بالشحنة والمستفيد وقابل للإلغاء وله صلاحية زمنية؛ إخفاء الموقع فور التسليم أو الإلغاء أو إنهاء المشاركة أو زوال التكليف، حتى عند تأخر عامل حذف البيانات. تحديد مشاركة الموقع أثناء الإرجاع بصورة مستقلة.
- عزل العميل والمتجر والعمليات ومنع كشف مسارات وعناوين عملاء آخرين أو رقم المندوب الخاص؛ نقل مشفر وتحديد معدل الإرسال وسياسة احتفاظ وتدقيق.
- واجهة عربية متجاوبة تعرض آخر تحديث ودقة الموقع وتحذر من انقطاع الاتصال أو قدم البيانات دون إيهام بحركة حية. متابعة حالة الطلب تبقى متاحة عند غياب الخريطة.
- اختيار مزود خرائط بعد دراسة التكلفة والشروط، وتحديث تكيفي لتقليل البيانات وإيقاف الاشتراكات عند انتهاء المشاهدة. لا يُوعد بتتبع خلفي موثوق عبر متصفح الهاتف قبل اختيار تطبيق المندوب المناسب.
- اختبار المشاركة مع جميع الأدوار، والعزل والانتحال وانتهاء المنح وإلغائها والتحديث القديم وضعف الاتصال وإعادة التكليف وانتهاء التوصيل. مراجعة الهاتف والحاسوب وقياس معدل التحديث وكلفة التشغيل؛ صورة خريطة أو محاكاة حركة لا تغلق المهمة.
